# v0.3 Implementation Plan - 详细实施计划

**版本**: v0.3

## 🎯 v0.3 目标概述

v0.3的核心目标是扩展游戏的核心玩法，支持更多玩家和更灵活的游戏配置。

**已完成的v0.3功能**:
- ✅ 移动动画系统
- ✅ 执行记录和历史回放

**待实现的核心功能**:
1. 多玩家支持 (3-4人)
2. 动态网格尺寸
3. 改进状态同步 (WebSocket)
4. 可配置质押设计

  ```solidity
  // 添加网格尺寸状态变量

  constructor(
    address _vault,

    uint8 _maxPlayers,

    uint8 _cols   // 新增

    require(_cols >= 3 && _cols <= 6, "Invalid grid cols");
    gridRows = _rows;
    gridCols = _cols;

    // 初始化grid
    _initializeGrid();
  }

  function _initializeGrid() internal {
    // 动态生成城堡位置
    _generateCastlePositions();
    // 分配玩家起始位置
    _assignStartingPositions();
  }

  function _generateCastlePositions() internal {
    // 算法：均匀分布城堡，避免角落和边缘
    // 确保每个玩家到最近城堡的距离大致相等
  }

  // 添加getter
  ```

#### Day 16-17: 前端网格系统重构
- [ ] **lib/constants/grid.ts重构**
  ```typescript
  // 从静态配置改为动态获取

  // 删除静态GRID_CONFIG
  // export const GRID_CONFIG = { rows: 3, cols: 3 }

  // 改为Hook
  export function useGridConfig(gameAddress: `0x${string}`) {
    const [config, setConfig] = useState({ rows: 3, cols: 3 })

    useEffect(() => {
      async function fetchGridSize() {
        const { rows, cols } = await getGridSize(gameAddress)
        setConfig({ rows: Number(rows), cols: Number(cols) })
      }
      fetchGridSize()
    }, [gameAddress])

    return config
  }

  // 辅助函数保持不变，但使用动态参数
  export function getGridCellPosition(
    x: number,
    y: number,
    gridConfig: { rows: number; cols: number }
  ) {
    const cellWidth = 100 / gridConfig.cols
    const cellHeight = 100 / gridConfig.rows

    return {
      left: `${x * cellWidth}%`,
      top: `${y * cellHeight}%`,
      width: `${cellWidth}%`,
      height: `${cellHeight}%`,
    }
  }
  ```
